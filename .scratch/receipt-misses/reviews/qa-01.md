  image count, effort). It also passes Turnstile siteverify.

  fresh visitor whose cookie had settled (load, clear, reload) so the one refund a day was there.
- Photos: the three real receipts (Malaysian hotel invoice, Cold Storage tax invoice, UK bill),

- Screenshots in `.scratch/receipt-misses/qa/shots/` (git-ignored, receipts are personal).
- Copy: every new string run through `uv run jura-growth check` from `repos/growth`: all pass
  (the two photo-number sentences pass with `{n}`; with a digit put in, the numbers rule flags them,
  as the developer noted).

## Exploratory charter (25 minutes): odd answers, double click, refresh, phone width, failures in sequence

- Double-clicking Read receipts sends one request (stand-in log shows one first call each time).
- Refresh during a slow read: the page comes back clean, no try taken, nothing left over.
- 360 px wide: no horizontal scroll; the not-a-receipt card puts the 96 px photo beside a narrow
  sentence column that wraps to six lines (readable; stacking it under the photo would read better).
  shots/x4-phone-360.png, x4-phone-360-busy.png.
- **Photo numbers can differ from the list the visitor saw.** With a refused HEIC as "Receipt 1" and
  a JPEG as "Receipt 2" in the upload list, a miss on the JPEG says "Photo 1" (its number in the
  batch sent, as ticket 02 specifies). The list is cleared after the read, so the thumbnail is the
  only link. Also, cards are titled "Receipt 4" while saying "Photo 1". Not a defect against the
  ticket; raised as a question. shots/explore-heic-then-photo-numbering.png.
- A not-a-receipt card is titled with whatever `merchant` the model gave it (the server keeps the
  fields on a not-a-receipt entry). Low; the server could blank them.
- When the second look answers with no usable reason (null) for an image the first read called
  "blurry", the less specific answer wins and the visitor sees the generic sentence. As specified
  ("the problem it gave"); worth keeping the first reason when the second has none.
- Quote builder offline (status 0) still says "Drafting isn't available right now" with no
  connection sentence; outside ticket 02's scope.
- Console: only the scripted failures, my own probes of revoked blob URLs, and Turnstile test-mode
  warnings.
